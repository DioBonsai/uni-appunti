## Valori di verità dei quantificatori (02:00 – 07:00)
Dominio D, predicato P(x):
1. **∃x.P(x) falsa** sse P(x) falsa per ogni x ∈ D.
2. **∃x.P(x) vera** sse P(x) vera per almeno un x ∈ D.
3. **∀x.P(x) vera** sse P(x) vera per ogni x ∈ D.
4. **∀x.P(x) falsa** sse P(x) falsa per almeno un x ∈ D.

Elenco numerato finale (06:00 – 09:00), con le quattro righe:
1. ∃x.P(x) falsa sse P(x) falsa per ogni x ∈ D
2. ∃x.P(x) vera sse P(x) vera per almeno un x ∈ D
3. ∀x.P(x) vera sse P(x) vera per ogni x ∈ D
4. ∀x.P(x) falsa sse P(x) falsa per almeno un x ∈ D

## Dualità (04:00 – 05:00)

## Leggi di De Morgan per i quantificatori (09:00 – 14:00)
Riga dei simboli: ¬ ~ ∧ ∨ → ↔ ∃ ∀. Poi:
- **¬∀x.P(x) = ∃x.¬P(x)** — «1° de Morg.»
- **¬∃x.P(x) = ∀x.¬P(x)** — «2° de Morg.»

Richiamo delle leggi di De Morgan ordinarie:
1. ¬(x ∧ y) = (¬x) ∨ (¬y)
2. ¬(x ∨ y) = (¬x) ∧ (¬y)
